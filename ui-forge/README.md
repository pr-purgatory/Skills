# UI Forge

Multi-platform UI app assistance: Swift (Apple), C#/.NET (Windows), and Rust (Linux).

## Overview
UI Forge provides native-aligned UI development assistance across Apple, Windows, and Linux platforms. It ensures platform-specific idioms are followed while maintaining strict separation between platform logic.

## Platform Specialists (Smiths)
- **apple-smith**: SwiftUI and Swift native development.
- **windows-smith**: C#/.NET (WinUI 3, WPF, MAUI).
- **linux-smith**: Rust-based UI (Tauri, Iced, Slint).

## Integration
Compatible with `@edm` event triggers for pro-active UI review and refinement.
